# Theme Studio — Android / Java + XML
Независимый редактор `.attheme`, GPL-2.0. Android 8.0+ (API 26), arm64-v8a.

## Работает в первой версии
- Предпросмотр чата и списка диалогов; нажатие на фон, текст, пузырь, шапку
  открывает соответствующий ключ. Предпросмотр **приближённый**, не Telegram UI.
- 805 стандартных цветов из официального DrKLO/Telegram от 13.10.2026.
- RGBA, HEX, живая смена цвета, отмена диалога без сохранения, стандартный цвет.
- Поиск ключей, история до 40 изменений, автосохранение между запусками.
- Импорт/экспорт `.attheme`, неизвестные числовые ключи, встроенные фотообои.
- Системный выбор фото: Google Фото доступно, если установлено и предоставляется
  системным проводником. Прямой интеграции Google Photos API нет.
- Нет INTERNET permission, аналитики, рекламы, AndroidX или Telegram account API.

## Сборка — только GitHub Actions
Откройте **Actions → Android release → Run workflow** для ветки
`arena/2e1290a9-hwhahhzwnwbzlkx`. Push изменений приложения также запускает сборку.
Gradle 8.11.1, AGP 8.9.2, JDK 17, SDK 35, NDK 27.2.12479018.
Workflow выполняет unit tests, lint, release/R8 и проверяет подпись и размер.
При размере больше **10 000 000 байт** job падает. APK в artifact
**ThemeStudio-signed-release** вместе с SHA256 и отчётом подписи.
Минимальная native ABI marker-библиотека собирается только для arm64-v8a;
другие архитектуры не упаковываются. Эмулятор x86 не поддерживается.

**Подпись:** стабильный публичный development PKCS12, без Secrets.
Это release-сборка с подписью, но **не безопасная production-идентичность**:
ключ доступен всем. См. [signing/README.md](signing/README.md).

## Что ещё не реализовано
Полная точная копия Telegram ChatMessageCell, все экраны и состояния, сложные
градиентные/анимированные обои, ручные UI-тесты на реальном устройстве,
доверенная production-подпись и публикация в Google Play. Не выдаём облегчённый
preview за пиксельную копию. APK и его размер считаются подтверждёнными только
после успешного workflow.

Официальные исходники сохранены в [upstream/telegram](upstream/telegram).
[Формат и первичные источники](docs/ATTHEME.md). Весь исходный код приложения
доступен в этом репозитории. Приложение не связано с Telegram официально.
