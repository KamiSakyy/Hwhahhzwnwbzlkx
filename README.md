# Ая — живая ИИ-тянка для Telegram

Бот, в котором **51 модель от 6 провайдеров работает как один ум**: автовыбор гонит
несколько моделей параллельно, на сложных вопросах три модели думают вместе и
судья собирает лучший ответ. В чате — никаких технических деталей: Ая просто живая.

**Умеет:** отвечать текстом, видеть фото и видео (кадры), читать документы
(txt/pdf/код…), слышать голосовые, искать в интернете (DuckDuckGo без ключей),
открывать ссылки, находить и присылать настоящие фото из интернета
(DDG Images → Openverse → Wikimedia), создавать и отправлять файлы.
Память каждого пользователя — SQLite `bot.db`, до 3 МБ истории.

## Запуск (Railway)
Dockerfile в корне: Railway сам соберёт и запустит `python run.py`.
Все ключи уже вшиты в `aibot/config.py`.

## Локально
```
pip install -r requirements.txt
python run.py
```
Нужен ffmpeg для понимания видео.

## Команды
- `/start` — познакомиться (и сбросить память)
- `/reset` — забыть разговор
