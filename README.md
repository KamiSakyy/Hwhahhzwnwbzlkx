# ✉️ Мессенджер «АРИ» — в ОДНОМ сообщении Telegram

**Фишка: бот отправляет тебе ровно ОДНО сообщение-экран и дальше только
редактирует его. Новых сообщений бот не создаёт — никогда.**
Пришло сообщение от собеседника → то же самое сообщение само обновилось.

Всё управление — обычным текстом. Каждое твоё сообщение бот мгновенно
удаляет, поэтому в чате всегда висит только один живой экран.

## 🚀 Деплой — одна кнопка

Railway → **New Project** → **Deploy from GitHub repo** → этот репозиторий →
**Deploy**. Всё. Токен уже вшит в `bot.py`, настроек нет.

## 📱 Как пользоваться

1. Открой бота, нажми /start — появится экран:
   `〔1〕 регистрация · 〔2〕 войти`
2. Напиши `регистрация` → бот по шагам спросит **почту**, **пароль** и
   **@юзернейм** (экран каждый раз перерисовывается и показывает, что введено;
   пароль виден только как •••••••• — он сразу удаляется из чата и хранится
   только в виде хэша, в открытом виде его нет нигде).
3. Напиши `войти` → экран превращается в **СООБЩЕНИЯ**: список диалогов,
   🔴 счётчики непрочитанных, твой @юзер и почта.
4. Напиши `поиск` → введи юзернейм → напиши `@юзернейм` → откроется диалог.
   В диалоге просто пиши текст — это и есть отправка сообщения.
   Собеседник получит его мгновенно: его единственное сообщение-экран
   само отредактируется (в открытом диалоге — сразу текст, в списке
   диалогов — 🔴 бейдж).

Команды: `регистрация` · `войти` · `поиск` · `@username` · `назад` ·
`профиль` · `выйти`

## 📁 Файлы (все в корне)

- `bot.py` — бот: один экран на юзера, только редактирование, удаление твоих сообщений
- `messenger.py` — аккаунты, поиск, переписка (SQLite), экраны
- `Dockerfile`, `railway.json`, `requirements.txt` — деплой, трогать не надо
- `test_messenger.py` — тесты (6 шт., все зелёные)

⚠️ Честно про данные: переписка хранится в файле `messenger.db` внутри
контейнера. При редеплое на Railway без тома база начнётся с чистого листа —
для постоянного хранения примонтируй Volume в `/app/data` (бот сам начнёт
писать базу туда, настроек в коде не нужно).
