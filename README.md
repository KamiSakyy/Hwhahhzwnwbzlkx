# 👹 DOOM в одном сообщении Telegram

Полноценный DOOM: рейкастинг в ASCII/Unicode-блоки, 3 уровня, враги с ИИ,
двери и ключ, пистолет и дробовик, аптечки и броня. Игра живёт в **одном**
сообщении бота — оно само редактируется ~5 раз в секунду, враги двигаются
в реальном времени. Твои текстовые команды **автоматически удаляются**,
чат не спамится.

## 🚀 Деплой — ОДНА кнопка

Railway → **New Project** → **Deploy from GitHub repo** → выбери этот
репозиторий → **Deploy**. Всё. Никаких переменных, портов и команд —
токен бота уже вшит в код (`TOKEN` в начале `bot.py`), `Dockerfile` и
`railway.json` лежат в корне, Railway сам всё подхватывает.

> ⚠️ 2026: у Railway нет вечного бесплатного тарифа — есть бесплатный
> триал ($5 кредита). После него нужен Hobby (~$5/мес), иначе бот встанет.

## 🎮 Как играть

Открой бота в Telegram и напиши `старт` (или нажми /start).
Дальше — обычным текстом (сообщения сами удалятся) или кнопками под игрой:

| Команда | Что делает |
|---|---|
| `вперёд` `назад` | движение |
| `влево` `вправо` | поворот |
| `шаг влево` `шаг вправо` | стрейф |
| `разворот` | на 180° |
| `огонь` | стрелять |
| `открыть` | дверь / замок |
| `оружие` | пистолет ⇄ дробовик |
| `карта` | миникарта |
| `пауза` | пауза |
| `выход` | закончить игру |
| `помощь` | справка в игре |

🎯 Цель: перебить всех, на 2-м уровне взять ⚿ ключ, дойти до портала `X`.
3 уровня, финальный босс — БАРОН.

## 📁 Файлы (все в корне!)

- `bot.py` — Telegram-бот: одно сообщение, цикл редактирования, удаление команд
- `doom_engine.py` — движок игры (рейкастер, враги, уровни), без Telegram
- `Dockerfile`, `railway.json` — деплой на Railway, трогать не надо
- `requirements.txt` — одна зависимость
- `test_doom.py` — тесты движка

Скорость редактирования упирается в лимиты Telegram (anti-flood): бот
целится в 5 FPS, при ошибке 429 сам замедляется и не теряет кадры в очередь.
