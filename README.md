# CutPro — видеоредактор для Android (Java + XML)

Монтаж видео на телефоне в духе CapCut: тёмный минималистичный интерфейс, компактная
панель инструментов, таймлайн с перетаскиванием пальцем и настоящий рендер через
**AndroidX Media3 1.5.1** (`media3-exoplayer`, `media3-ui`, `media3-transformer`, `media3-effect`).

Никакого Kotlin, никаких эмодзи, никаких гигантских кнопок — только иконки и панели.

## Возможности

**Таймлайн**
- Плейхед закреплён по центру: тянешь ленту пальцем — кадр меняется под пальцем
  (как в CapCut), пинч — зум.
- Миниатюры клипов повторяются по всей длине, подписи, подсветка выбранного клипа.
- **Ручки обрезки прямо на выбранном клипе** — тянешь край и обрезаешь, не открывая панель.
- **Долгое нажатие на клип — перетаскивание** его на другое место в ленте.
- **Дорожка музыки** под лентой с волной; касание открывает панель музыки.
- Линейка со временем, авто-обновление позиции при проигрывании.

**Обрезка**
- Отдельный режим: исходник клипа на всю ширину, две жёлтые ручки тянутся пальцем,
  кадр в превью обновляется на лету, показываются начало/конец/длительность.

**Монтаж**
- Несколько видео за раз, разрез по плейхеду (с переносом текстовых слоёв),
  перемещение, дублирование, удаление.
- Скорость 0.25×–4× слайдером + пресеты; громкость клипа 0–200 %.
- 8 фильтров (ч/б, негатив, тёплый, холодный, сочный, ночь, кино) плюс цветокоррекция:
  яркость, контраст и тепло слайдерами — всё видно в превью и попадает в файл.
- Форматы кадра 9:16, 16:9, 1:1, 4:5.

**Звук**
- **Звук из видео**: выбираешь ролик — CutPro вытаскивает дорожку через Transformer
  (`setRemoveVideo`) в отдельный M4A и ставит её музыкой проекта.
- Звук можно взять и из любого клипа проекта одной кнопкой.
- Отдельный аудиофайл из проводника, зацикливание на всю длину, своя громкость.
- **Громкость клипа 0–200 %** действует сразу в превью и в экспорте; 0 % — настоящая
  тишина (`setRemoveAudio`), музыка при этом продолжает играть.
- Тумблер **«Оригинальный звук: выкл»** убирает звук всех клипов, оставляя музыку.
- Превью играет клипы и музыку одновременно (два плеера), экспорт микширует дорожки.
- Скорость клипа пересчитывает и его звук (`SpeedChangingAudioProcessor`), без рассинхрона.

**Текст**
- Слой поверх видео: текст, размер, 6 цветов, позиция (сверху/центр/снизу), время показа.
- В превью — настоящие TextView (долгое нажатие удаляет), в экспорте — `BitmapOverlay`.

**Прочее**
- Отмена и повтор действий (до 40 шагов).
- Цветокоррекция: яркость, контраст, насыщенность (`HslAdjustment`), тепло;
  кнопка «Ко всем клипам» переносит эффект на весь проект.
- Текст в превью перетаскивается вверх/вниз (сверху / центр / снизу).
- Экспорт 720p / 1080p, H.264 + AAC, прогресс и отмена, автосохранение в
  Галерею `Movies/CutPro`.
- Библиотека проектов сеткой с настоящими миниатюрами, переименование и удаление.

## Структура

```
app/src/main/java/com/kamisakyy/cutpro/
  MainActivity.java        — библиотека проектов (сетка 2 колонки, миниатюры)
  EditorActivity.java      — редактор: превью, таймлайн, панели, undo/redo, экспорт
  TimelineView.java        — кастомный таймлайн: центр-плейхед, скраб, зум, обрезка
  VideoExporter.java       — Composition + Transformer, текстовые оверлеи, прогресс
  AudioExtractor.java      — видео → звук (M4A) через Transformer
  AspectFrameLayout.java   — превью с точным соотношением сторон
  Project.java             — модель проекта/клипа/текста и JSON
  ProjectStore.java        — хранение проектов
  FilterPresets.java       — цветовые эффекты для превью и экспорта
  GainAudioProcessor.java  — громкость клипов и музыки (PCM 16-bit)
  MediaSaver.java          — публикация результата в Галерею
app/src/main/res/
  layout/  activity_main, activity_editor, item_project, item_new_project,
           panel_text, panel_music, dialog_progress
  drawable/  векторные иконки инструментов и фоны
  values/  цвета, стили, строки
```

## Сборка

GitHub Actions запускает workflow **Build APK** на каждый push и публикует подписанный APK
в релиз **latest-apk**:

```
https://github.com/KamiSakyy/Hwhahhzwnwbzlkx/releases/download/latest-apk/CutPro-latest.apk
```

Локально: Android Studio, AGP 8.7.3 / Gradle 8.9 / JDK 17, `compileSdk 35`, `minSdk 29`,
`./gradlew :app:assembleRelease`.

Подпись — демонстрационный ключ из `signing/` (SHA-256 в `signing/CERT-SHA256.txt`),
поэтому обновления ставятся поверх без удаления. Для реального релиза задайте секреты
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
