# Telegram Theme Editor

Android (Java + XML) app for creating Telegram themes with live preview.
Design and theme keys are based on the official DrKLO/Telegram source code.

Features:
- Tap any preview element to change its color and alpha.
- Pick a wallpaper from gallery/Google Photos.
- Export a `.attheme` file.

Build: GitHub Actions (Gradle + Android SDK), release APK, arm64-v8a, signed.
